# Security Policy

## Reporting a Vulnerability

Report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue.

## Supported Versions

Security fixes are released for the latest version only.

## Scope

Loadout writes files into your repository and generates the instruction files coding agents read. Reports are especially useful when they show a way to:

- write or read files outside the repository
- get unreviewed content into `CLAUDE.md`, `AGENTS.md`, or `GEMINI.md`
- run code through the generated Git hooks
